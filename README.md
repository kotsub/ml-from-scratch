# ML from scratch

Три учебных алгоритма на **Python + NumPy**: kNN-классификатор, линейная регрессия
градиентным спуском с L2 и CART-дерево классификации с критерием Gini.
В реализации алгоритмов нет scikit-learn; библиотека используется для наборов данных,
разбиений, метрик и проверки результатов.

## Запуск

Linux / Ubuntu, Python 3.12 или 3.13, из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python -m examples.compare_models
jupyter lab
```

В Windows PowerShell: `.venv\Scripts\Activate.ps1` для активации среды.
Проверенные версии сохранены в `requirements-lock.txt`.
Первичная установка зависимостей требует интернет; обучение и примеры работают без сети.
Наборы breast_cancer, diabetes и iris поставляются вместе со scikit-learn.

Открой [notebooks/01_algorithms.ipynb](notebooks/01_algorithms.ipynb):
он разбирает расстояния и голосование, градиентный спуск и пороги дерева на маленьких примерах.

## Пример

```python
from ml_scratch import KNNClassifier, LinearRegressionGD, DecisionTreeClassifier

knn = KNNClassifier(n_neighbors=1).fit([[0], [1], [5]], [0, 0, 1])
print(knn.predict([[4]]))  # [1]

linear = LinearRegressionGD(learning_rate=0.05).fit([[0], [1], [2]], [1, 3, 5])
print(linear.predict([[3]]))  # около 7

tree = DecisionTreeClassifier(max_depth=2).fit([[0], [1], [5], [6]], [0, 0, 1, 1])
print(tree.predict_proba([[4]]))  # [[0. 1.]]
```

Для реальных данных сначала стандартизируй признаки для kNN и GD:
`StandardScaler().fit(X_train)` и затем `.transform` для train и test.
Дереву стандартизация не требуется. Пропуски и категориальные признаки нужно обработать заранее.

## Реализации

| Файл | Содержание | Основные параметры |
|---|---|---|
| `ml_scratch/knn.py` | Евклидово расстояние, равные голоса соседей, вероятности как доли голосов | `n_neighbors` |
| `ml_scratch/linear.py` | Полный градиентный спуск, свободный член, история функции потерь | `learning_rate`, `max_iter`, `l2`, `tol` |
| `ml_scratch/tree.py` | Поиск порога по Gini, рекурсивное построение, вероятности в листьях, важности | `max_depth`, `min_samples_split`, `min_samples_leaf` |

Все модели имеют `fit(X, y)` и `predict(X)`, классификаторы — `predict_proba(X)`.
Возвращаются исходные метки классов; порядок столбцов вероятностей соответствует `classes_`.
Это небольшой учебный API, без полной совместимости со sklearn Pipeline/GridSearchCV.

Цель линейной регрессии:

$$J(w,b)=\frac{1}{2n}\sum_i(x_i^T w+b-y_i)^2+\frac{\lambda}{2}\|w\|_2^2.$$

Градиенты: `X.T @ residual / n + l2 * w` и `mean(residual)` для свободного члена.
Свободный член не регуляризуется. Для сравнения со sklearn Ridge нужно
`alpha = n * l2`: нормировки функций потерь отличаются.

## Проверки и ограничения

Тесты проверяют известное аналитическое решение регрессии, эквивалентность Ridge,
совпадение kNN с библиотекой, Gini-разбиение, XOR, ограничения листьев, один класс,
постоянные признаки, неизвестную размерность и некорректные входы.
GitHub Actions выполняет тесты и сравнение на Python 3.12/3.13.

- kNN хранит все train-объекты и сортирует расстояния для каждого запроса: это просто,
  но медленно на больших данных. Равные расстояния разрешаются порядком train-строк,
  равные голоса — порядком `np.unique`.
- GD зависит от масштаба и learning rate. При исчерпании `max_iter` сходимость
  не гарантируется; смотри `loss_history_` и `n_iter_`.
- Дерево работает с числовыми признаками, без pruning, sample weights и обработки NaN.
  При равном выигрыше выбирается первый признак и первый порог. Поэтому структура
  может отличаться от sklearn. Неограниченная глубина на больших данных может упереться
  в предел рекурсии Python.
- Один split и одиночные измерения времени не доказывают общую точность или скорость.
  breast_cancer используется только как учебный набор классификации.

Для разбора на собеседовании: объяснить выбор k, влияние масштаба, формулу градиента,
зачем нужна L2, как считается Gini и как глубина дерева влияет на переобучение.
