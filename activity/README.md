# Автоматический журнал

GitHub Actions раз в день запускает тесты и добавляет сюда запись после успешной
проверки. Эти коммиты создаются автоматически и отмечают работу workflow.
Они не означают ручную доработку алгоритмов в этот день.

Расписание: ежедневно около **12:17 по Москве** (09:17 UTC). Возможны задержки
планировщика GitHub. Повторный запуск в тот же день не создаёт ещё один коммит.
Компьютер владельца для запуска не нужен. Автор коммитов — аккаунт `kotsub`,
используется его GitHub noreply-адрес; даты коммитов соответствуют моменту запуска.

Запустить вручную: **Actions → Daily activity → Run workflow**.
Отключить: **Actions → Daily activity → ⋯ → Disable workflow**.
Настройки: [daily-activity.yml](../.github/workflows/daily-activity.yml).

Если GitHub отключит расписание после длительного отсутствия активности,
включи workflow во вкладке Actions. Историю прошлых дней скрипт не заполняет.
